# Pano 图形界面设计

## 1. 设计目标

- **信息密度高、实时性强**：监控面板一屏看全；
- **适配器管理直观**：启停、配置、状态一目了然；
- **主题可切换**（默认暗色）；
- **UI 与数据解耦**：只按能力 / series 取数，UI 整体可替换。

## 2. 整体布局

```
┌─────────┬──────────────────────────────────────┐
│  侧边栏  │            主内容区（页面）            │
│          │                                      │
│  ● 仪表盘 │   ┌──────────────────────────────┐  │
│  ⚙ 适配器 │   │  面板 A         面板 B        │  │
│   设置   │   │                              │  │
│          │   └──────────────────────────────┘  │
│          │   ┌──────────────────────────────┐  │
│  [版本]   │   │  面板 C                      │  │
│          │   └──────────────────────────────┘  │
├─────────┴──────────────────────────────────────┤
│  状态栏：核心运行状态 · 适配器运行数 · 错误数     │
└───────────────────────────────────────────────┘
```

- **侧边栏**：页面导航（图标 + 文本），底部版本号；
- **主内容区**：当前页面；
- **状态栏**：全局健康度（运行中适配器 N/M、错误 N）与采样节拍。

## 3. 页面

### 3.1 仪表盘（示例）

- M1 用于验证数据链路：两个示例面板——counter 数值卡、sine 实时曲线；
- 面板组件：标题 + 最新值 + 最近窗口曲线（egui_plot）；
- 空态：无可用的 series 时显示「无数据」引导文案。

### 3.2 适配器管理（初期重点）

表格形式，每行一个适配器：

| 列 | 内容 | 交互 |
| --- | --- | --- |
| 状态 | 徽标（绿=运行 / 灰=停止 / 黄=启动中 / 红=错误） | 悬停 tooltip 显示错误详情 |
| 适配器 | 名称 + id + 描述 | — |
| 能力 | capability 标签 | — |
| 采样间隔 | 可编辑数字 + 单位 | 修改即热重载 |
| 启用 | Switch | 切换启停 |
| 操作 | 重启按钮（Error 状态可用） | 手动恢复 |

- **配置表单由 `config_schema` 驱动渲染**（数值 / 文本 / 枚举 / 开关），避免 UI 硬编码适配器参数；
- 修改配置 → 写回 `pano.toml` → 仅重启该适配器 → 成功 / 失败 toast 提示。

### 3.3 设置

- 主题（暗 / 亮）、默认采样间隔、环形缓冲容量；
- 查看当前 `pano.toml` 配置。

## 4. 组件与视觉规范

- 字体：系统默认 + 中文回退（M1 验证中文渲染）；
- 暗色默认色板：
  - 背景 `#1e1e1e`、面板 `#252526`、边框 `#333`；
  - 强调色 `#4f9cf9`（蓝）；
  - 状态色：成功 `#3fb950` / 警告 `#d29922` / 错误 `#f85149`；
  - 曲线色板：蓝 / 青 / 绿 / 橙 / 紫，依序取用；
- 间距 8px 基准；面板圆角 4px；状态徽标 = 圆点 + 文字；
- 基于 egui 默认 `visuals` 定制，不引入重量级主题库。

## 5. 渲染与刷新策略

- egui 默认只在交互时重绘；**数据驱动重绘**：core 收到新样本时 `request_repaint()`（节流：距上次请求 > 采样间隔 / 2）；
- 帧率上限可配置（默认 60fps，空闲时降低）；
- 曲线只取最近 N 个样本（如 300 点）绘制，避免每帧重算全量历史。

## 6. 交互细节

- 启停 / 重启有状态反馈：进行中禁用按钮，toast 显示结果；
- Error 状态：行内红色徽标 + 悬停 tooltip 显示最后错误；
- 空数据 / 未启用适配器的面板显示空态，而不是 0；
- 文案走常量表：M1 中文硬编码，M3 抽 key 预留 i18n。

## 7. 可替换性说明（UI 侧）

- `pano-ui` 是独立 crate，入口接收 `CoreHandle`（只读 API）+ `UISpec` 声明；
- 新 UI = 新 crate 实现同一接入协议；egui 的页面、主题、组件都属于本 crate 内部实现，不影响其他层。
