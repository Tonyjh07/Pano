# Pano 图形界面设计

## 1. 设计目标

- **信息密度高、实时性强**：监控面板一屏看全；
- **多窗口 + 托盘常驻**：各 UI 独立窗口，可单独置顶 / 全屏；应用驻留系统托盘；
- **适配器管理直观**：启停、配置、状态一目了然；
- **主题可切换**（默认暗色）；
- **UI 与数据解耦**：只按能力 / series 取数，UI 整体可替换。

## 2. 窗口模型（多窗口 + 托盘）

```
┌──────────────────────────────┐
│  系统托盘（Pano 常驻入口）      │
│  ├ 打开管理窗口（适配器+设置）  │
│  ├ 监控组件窗口列表            │
│  └ 退出                      │
└──────────────────────────────┘
```

| 窗口 | 内容 | 说明 |
| --- | --- | --- |
| **管理窗口**（独立） | 适配器管理页 + 全局设置页（合并为一个窗口，页签切换） | 从托盘打开；可置顶 / 全屏 |
| **监控组件窗口**（零到多个） | 每个信息 / 曲线 UI 组件一个独立窗口 | 组件自由设置窗口（置顶 / 全屏 / 大小 / 位置）；可随时在托盘菜单打开 / 聚焦 |

关键语义：

1. **无传统主窗口**：应用驻留系统托盘；关闭任何窗口 = 隐藏（`CancelClose` + `Visible(false)`），**不退出进程**；托盘「退出」才是真正结束；
2. **组件级窗口自由**：每个 UI 组件可声明自己的窗口需求（标题 / 尺寸 / 置顶开关 / 全屏开关），由 pano-ui 的**窗口管理器**统一创建 / 管理 viewport；组件也可选择不独立成窗（未来 dock 形态预留）；
3. **置顶 / 全屏由组件实现**：窗口内提供「置顶」「全屏」切换按钮（egui 自定义标题栏按钮或窗口内按钮），运行期通过 `ViewportCommand::WindowLevel` / `Fullscreen` 动态切换；
4. **数据流不变**：所有窗口读同一个 `SampleStore` 快照（RwLock 读端），控制走同一个 `Lifecycle`；窗口数量不影响 core / adapters；
5. **重绘**：数据变化时对**所有打开的 viewport** 触发 `request_repaint_after_for`（节流策略同 §6）；
6. **关闭顺序**（架构 §5）：托盘「退出」→ 停止全部适配器 → 结束进程。

## 3. 管理窗口（适配器 + 设置）

合并为一个独立窗口，内部页签切换：

### 3.1 适配器管理（初期重点）

表格形式，每行一个适配器：

| 列 | 内容 | 交互 |
| --- | --- | --- |
| 状态 | 徽标（绿=运行 / 灰=停止 / 黄=启动中 / 红=错误） | 悬停 tooltip 显示错误详情 |
| 适配器 | 名称 + id + 描述 | — |
| 能力 | capability 标签 | — |
| 采样间隔 | 可编辑数字 + 单位 | 修改即热重载 |
| 启用 | 开关 | 切换启停 |
| 操作 | 重启按钮（Error 状态可用） | 手动恢复 |

- **配置表单由 `config_schema` 驱动渲染**（数值 / 文本 / 枚举 / 开关），避免 UI 硬编码适配器参数；
- 修改配置 → 写回 `pano.toml` → 仅重启该适配器 → 成功 / 失败 toast 提示。

### 3.2 全局设置

- 主题（暗 / 亮）、默认采样间隔、环形缓冲容量；
- 查看当前 `pano.toml` 配置；
- M1 为骨架，M3 完善。

## 4. 监控组件窗口（信息与曲线）

- 每个信息 / 曲线面板为一个 **UI 组件**，默认独立窗口；
- 组件窗口内容：标题 + 最新值 + 最近窗口曲线（egui_plot）+ 窗口控制（置顶 / 全屏按钮）；
- 空态：无 series 时自然没有组件窗口；在管理窗口查看适配器启用状态（无数据时无「0」误导）；
- 组件可自由设置：窗口标题、初始尺寸 / 位置、是否允许置顶 / 全屏；
- 托盘菜单列出全部监控组件窗口，点击打开 / 聚焦。

## 5. 组件与视觉规范

- 字体：系统默认 + 中文回退（M1 已验证中文渲染）；
- 暗色默认色板：
  - 背景 `#1e1e1e`、面板 `#252526`、边框 `#333`；
  - 强调色 `#4f9cf9`（蓝）；
  - 状态色：成功 `#3fb950` / 警告 `#d29922` / 错误 `#f85149`；
  - 曲线色板：蓝 / 青 / 绿 / 橙 / 紫，依序取用；
- 间距 8px 基准；面板圆角 4px；状态徽标 = 圆点 + 文字；
- 基于 egui 默认 `visuals` 定制，不引入重量级主题库。

## 6. 渲染与刷新策略

- egui 默认只在交互时重绘；**数据驱动重绘**：core 收到新样本时对所有打开的窗口 `request_repaint`（节流：距上次请求 > 采样间隔 / 2）；
- 帧率上限可配置（默认 60fps，空闲时降低）；
- 曲线只取最近 N 个样本（如 300 点）绘制，避免每帧重算全量历史。

## 7. 交互细节

- 启停 / 重启有状态反馈：进行中禁用按钮，toast 显示结果；
- Error 状态：行内红色徽标 + 悬停 tooltip 显示最后错误；
- 空数据 / 未启用适配器的面板显示空态，而不是 0；
- 窗口控制：每个窗口「置顶」「全屏」按钮，运行期切换；
- 文案走常量表：M1 中文硬编码，M3 抽 key 预留 i18n。

## 8. 可替换性说明（UI 侧）

- `pano-ui` 是独立 crate，入口接收 `CoreHandle`（只读 API）+ `UISpec` 声明；
- **窗口模型是 pano-ui 内部实现**：多窗口 / 托盘 / 置顶 / 全屏均不改变与其他层的契约——新 UI = 新 crate 实现同一接入协议，窗口形态由各 UI 自由决定；
- 托盘集成（`tray-icon`）属于 pano-ui 内部（或 pano-app 装配层），不影响 core / adapters。

## 9. 技术要点（egui 0.36 已验证）

| 需求 | 实现 |
| --- | --- |
| 多独立窗口 | `Context::show_viewport_deferred`，每帧声明，窗口管理器统一调度 |
| 置顶 / 全屏 | `ViewportBuilder::with_window_level(AlwaysOnTop)` / `with_fullscreen`；运行期 `ViewportCommand::WindowLevel` / `Fullscreen` |
| 隐藏不退出 | 关闭请求 → `CancelClose` + `ViewportCommand::Visible(false)` |
| 托盘 | `tray-icon` crate；菜单事件经 muda 全局 channel 由泵送线程接收（共享命令队列），经 `egui_ctx.request_repaint()` 唤醒 UI；主线程帧内消费命令 |
| 跨窗口重绘 | `Context::request_repaint_after_for(duration, ViewportId)` 对指定窗口触发 |
